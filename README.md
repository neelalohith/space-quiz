# Orbit — Space Exploration Quiz

A polished, dependency-free space exploration quiz built as a single HTML file. Test your knowledge across 10 questions, track your score, and get colorful feedback as you travel through the cosmos.

## Features

- 10 space-themed questions
- Live score counter and progress bar
- Green correct-answer feedback
- Red wrong-answer feedback with a shake animation
- Emoji-based results screen with replay support
- Responsive, narrow-column layout
- Light and dark themes using `prefers-color-scheme`
- Keyboard-accessible native buttons
- Reduced-motion support
- No server, build step, or external dependencies

## Run locally

Open [`index.html`](./index.html) directly in a browser. No installation or server is required.

```text
file:///path/to/space_quiz/index.html
```

## Project structure

The entire app lives in [`index.html`](./index.html):

- HTML defines the start, quiz, and results screens.
- CSS provides the responsive layout, themes, animations, and feedback states.
- JavaScript contains the question data, quiz state, scoring, and screen transitions.
